# firmware/ · ESP32-S3 固件（单传感器 demo 版）

文件：`touch_doll.ino` —— 每 120ms 读一次 GPIO4 的 FSR402 压力值 → WiFi POST `{"bd":力度}` 到电脑上的 touch-server。

## 接线（单传感器，5 步）

面包板一条竖线的 5 个孔相通，把它当"把几根线拧在一起"的工具：

1. **FSR402 一条腿** → 插到**第 8 列**（这列再插一根杜邦线 → 板子 **3V3**）
2. **FSR402 另一条腿** → 插到**第 9 列**（两条腿必须不同列！）
3. **信号线**：绿线一头插 9 列，另一头 → 板子 **GPIO4**（ADC1，GPIO1-10 才可用）
4. **10KΩ 电阻**：只插在面包板上 —— 一条腿插 9 列（跟 FSR 另一条腿同列），
   另一条腿插旁边随便一列（10/11/12 列都行）。电阻腿短，只负责在面包板内"跨一步"，够不到板子很正常
5. **黑线（负极线）**：一头插电阻另一条腿所在的那一列，另一头插板子上印着 **GND** 的针脚
   —— 软线想多长多长，多远都够得到
6. 电路 = 3V3(+) —FSR— ●信号点(GPIO4) —10KΩ— GND(−)；按得越重，信号点电压越高

> 以后加传感器：照此每路多占一条竖线 + 一个 ADC 针脚 + 一颗 10K，改固件里的 PINS/KEYS 数组即可（教程 8 路版思路一致；多路时建议用闲置 GPIO 拉低当接地桩，绕开面包板蓝排）。

## 烧录要点（教程避坑实录浓缩）

- Arduino IDE 装 ESP32 板支持包，选 **ESP32-S3** 板型
- 认准标 **USB** 的 Type-C 口（另一个是 COM/UART，烧不进）
- 必须用**数据线**，充电线烧不了程序
- 不跑 / 卡死：先 `esptool erase_flash` 全片擦除，再带参数烧录：
  `FlashMode=dio, FlashSize=16M, PSRAM=opi`
- 下载模式：按住 BOOT 点一下 RST

## 验证

烧录后按传感器，touch-server 终端应出现：

```
22:35:58  肚子 · 抱住不放 · 力度4095 · 3.25秒
```

没反应先查：WiFi 是否连上（板子串口监视器看 IP）、电脑 IP 对不对、防火墙有没有放行 9333。
