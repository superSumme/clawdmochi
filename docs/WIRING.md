# 接线教程 · ESP32-S3 + FSR402 压力传感器

> 目标：把一枚 FSR402 薄膜压力传感器接到 ESP32-S3，让板子能读出"你什么时候摸了它、多用力、多久"。
> 全程免焊接，只需面包板 + 杜邦线 + 一颗 10KΩ 电阻。

配套示意图：[docs/wiring_demo.png](wiring_demo.png)（建议先打开对照看）。

---

## 1. 需要哪些材料

| 材料 | 数量 | 说明 |
|---|---|---|
| ESP32-S3 开发板 | 1 | 16MB Flash / 8MB PSRAM 版本；板上有两个 Type-C 口，认准标 **USB** 的那个 |
| FSR402 薄膜压力传感器 | 1 | 圆片形"皮肤"，两条腿是薄膜印的银线 |
| 10KΩ 电阻 | 1 | 色环 棕-黑-橙-金；分压用，不分正负极 |
| 面包板 | 1 | 半尺寸即可 |
| 杜邦线 | 3~4 根 | 红（正极）、绿（信号）、黑（负极），软硬都行 |
| 数据线 | 1 | **必须是数据线**，纯充电线烧不进程序 |

> FSR402 的腿是薄膜印刷线路，**不要折腿根**，容易折断。多买一两片备用。

---

## 2. 先弄懂电路（30 秒）

FSR402 本质是"按得越重、电阻越小"的可变电阻。它自己不会输出电压，所以要和 10KΩ 电阻组成**分压电路**：

```
3V3(正极) ── FSR402 ──●── 10KΩ ── GND(负极)
                      │
                   GPIO4（只"看"电压，不供电）
```

- 没按：FSR 电阻很大 → 信号点电压接近 GND → 读数接近 0
- 按住：FSR 电阻变小 → 信号点电压被拉高 → 读数变大（0~4095）

**为什么用 GPIO4**：ADC 读数只有 **GPIO1~10（ADC1）** 能在 WiFi 开着时正常工作；GPIO11~20 属于 ADC2，会和 WiFi 抢资源导致读数乱跳甚至连不上 WiFi。

---

## 3. 面包板怎么插（关键：列 = 节点）

面包板**同一竖列的 5 个孔内部相通**，把它当成"把几根线拧在一起"的工具。图里用第 8、9、11 列。

按下表一步步插：

| 步骤 | 操作 | 对应图中颜色 |
|---|---|---|
| ① | FSR402 **一条腿**插到第 **8 列**；同列再插一根线接到板子 **3V3** | 红（正极） |
| ② | FSR402 **另一条腿**插到第 **9 列**（两条腿必须不同列！） | — |
| ③ | 一根线：一头插 **9 列**，另一头接板子 **GPIO4** | 绿（信号） |
| ④ | 10KΩ 电阻：一条腿插 **9 列**（和 FSR 一起），另一条腿插 **11 列** | 紫（电阻） |
| ⑤ | 一根线：一头插 **11 列**，另一头接板子 **GND** | 黑（负极） |

完成后电流路径（从正极绕一圈回负极，回路才通）：

```
板子 3V3 → 红线 → 8 列 → 穿过 FSR 圆片 → 9 列
         → 10KΩ 电阻 → 11 列 → 黑线 → 板子 GND
GPIO4 的绿线只从 9 列"看"电压，不供电
```

> 电阻腿短，只负责在面包板内部"跨一列"，够不到板子很正常，不用硬拉。
> 软的杜邦线想多长多长，接板子那头完全够得到。

---

## 4. 对照检查（通电前必做）

- [ ] FSR 两条腿在**不同列**（8 和 9）
- [ ] 红线：`8 列 → 3V3`
- [ ] 绿线：`9 列 → GPIO4`
- [ ] 10KΩ 电阻跨在 `9 列 ↔ 11 列`
- [ ] 黑线：`11 列 → GND`
- [ ] 没有任何两根线把 **3V3 和 GND 直接短接**（会烧板子）

> 正负不能接反、更不能直接相碰。不过 FSR 和 10KΩ 电阻本身都不分正负极，接反了顶多读数异常，不会坏。

---

## 5. 通电验证

1. 用数据线把板子接到电脑，认准标 **USB** 的 Type-C 口。
2. 打开 Arduino IDE 串口监视器，波特率设 **115200**。
3. 板子重启后应看到类似：

```
=== touch_doll 启动 ===
[wifi] 连上了 IP=192.168.x.x
[beat 16] bd=12   WiFi=OK   POST=200
```

4. 用手指按 FSR 圆片，`bd=` 后的数值应明显变大（松手接近 0，按重可到 2000~4095）。

- `POST=200`：数据成功送到电脑服务器 ✅
- `POST=-1`：服务器地址不对或没启动
- `POST=-99`：WiFi 没连上
- 读数一直乱漂：检查 FSR 是否悬空、面包板触点是否松动；多路时建议用闲置 GPIO 拉低当"接地桩"绕开面包板蓝排。

## 6. 常见问题

**Q：读数一直是 0？**
检查红线是否接到 3V3、FSR 两条腿是否分列、有没有按到圆片中心。

**Q：读数一直是满值 4095 不变化？**
检查 9 列和 GND 之间是否接了 10KΩ 电阻；没有电阻信号会被直接拉到 3V3。

**Q：WiFi 连不上？**
必须用 **2.4G** 频段 WiFi（ESP32-S3 不支持 5G）；密码区分大小写。

**Q：以后想加更多传感器？**
每路多占一条竖列 + 一个 ADC 针脚（仍限 GPIO1~10）+ 一颗 10KΩ 电阻，然后改固件顶部的 `SENSOR_PIN`/`KEY` 或数组即可（多传感器映射在 `touch_server/posmap.py` 已预留）。
